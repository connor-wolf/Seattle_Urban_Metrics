# Data Sources 
Hyperlinks to the webpages where the datasets used in this project are hosted are included below. Note that no CSV file from the Environmental Protection Agency's (EPA) Smart Location Database (SLD) is included here due to its large size. 

- EPA Smart Location Database: https://www.epa.gov/smartgrowth/smart-location-mapping
- Tree Canopy Data: https://data-seattlecitygis.opendata.arcgis.com/datasets/SeattleCityGIS::seattle-tree-canopy-2021-tree-crowns/about
- Vacancy Rate Data: https://data.seattle.gov/dataset/Apartment-Market-Vacancy-by-Census-Tract/93bk-qn72/about_data
- Rent Typology: https://catalog.data.gov/dataset/apartment-market-rent-prices-by-census-tract 

# Notes
Each of these datasets can be found on data.gov or data.seattle.gov. Seattle was chosen as the host city for these questions in part because of the city's public data collection initiatives.
